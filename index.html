מערכת ניהול התורים לטיפולים לא נשארה דמו — היא רצה בפועל ומשרתת משתמשים אמיתיים, כולל תחזוקה שוטפת.

ספרייה בקוד פתוח

NexusDB פורסמה כקוד פתוח בגיטהאב — ממשק אחיד מעל חמישה מסדי נתונים שונים, כתוב פעם אחת בלבד.

ארכיטקטורת מיקרו-שירותים

Domix נבנתה משלושה שירותים נפרדים — אימות, API ושער Nginx — ולא כמונוליט אחד, כדי שכל חלק יתפתח ויתוחזק בנפרד.

עיבוד מסמכים אוטומטי עם AI

צינור OCR ומודל ראייה שקורא חשבוניות סרוקות, מחלץ שדות ומסווג אותן — בלי הקלדה ידנית של אף שורה.

תוסף Electron שמתחבר ישירות ל-SQL Server ולחשבשבת, ועוקף מגבלות ממשק מקורי בלי לגעת בליבת המערכת.
